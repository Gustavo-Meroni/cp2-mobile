# Roteiro de demonstração — TaskFlow

Duração sugerida: **4 a 5 minutos**. Grave a tela do celular com o app em execução e narre as ações. Mostre o resultado de cada operação antes de passar à próxima.

| Tempo | Demonstração |
| --- | --- |
| 0:00–0:35 | Apresente o objetivo do app, as três abas e as tecnologias principais: React Native, Expo, TypeScript, React Navigation, Context API, AsyncStorage e Fetch. |
| 0:35–1:15 | Mostre uma tentativa de login inválida. Entre com `admin / 123` e destaque que Configurações abriu primeiro; mostre nome, perfil, tratamento e tema. |
| 1:15–1:45 | Faça logout e entre com `user / 123`. Mostre que a Home abriu primeiro, a frase da API e o botão **Outra frase**. |
| 1:45–2:50 | Vá a Tarefas. Tente salvar um formulário inválido, depois crie uma tarefa válida. Abra detalhes e mostre status, prioridade, categoria e datas. |
| 2:50–3:35 | Edite a tarefa, altere o status e use os filtros. Mostre o estado vazio de um filtro sem resultados. |
| 3:35–4:15 | Tente excluir e cancele a confirmação; depois confirme a exclusão. Crie outra tarefa para demonstrar a persistência. |
| 4:15–4:45 | Feche e reabra o app: mostre a sessão e a tarefa restauradas. Alterne o tema, reabra novamente e mostre que a escolha permaneceu. |
| 4:45–5:00 | Relembre que tarefas de `admin` e `user` são separadas; encerre mostrando o link do repositório e os integrantes. |

Antes de enviar, confira se o vídeo tem **entre 3 e 7 minutos**, o áudio está claro, o repositório está acessível ao professor e o README contém o link do vídeo caso ele esteja online.
